# Security Policy

Report suspected vulnerabilities privately to the repository owner. Do not include applicant information, credentials, session cookies, or live evidence in GitHub issues.

The hosted workbench uses individual roles, scrypt password hashes, optional TOTP, login throttling, revocable idle-expiring sessions, transactional storage, append-only application audit events, controlled attachment types, integrity hashes, and verified snapshots. These controls reduce risk but do not constitute agency authorization or regulatory certification.

Real records may be used only after the responsible agency approves the hosting environment, accounts, data classification, retention, backup, incident response, and integrations.
